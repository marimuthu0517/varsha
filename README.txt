VARSHAA — EMOTIONAL BIRTHDAY WEBSITE

This version is intentionally more emotional and animated:
- cinematic intro and heartbeat
- floating stars and click hearts
- animated love cards
- polaroid memory wall with photo lightbox
- emotional timeline
- interactive envelope with typewriter letter
- final wish reveal with heart burst
- responsive mobile design
- Jujutsu-Kaisen-inspired purple/blue atmosphere without copying official artwork

Open index.html in a browser or use VS Code Live Server.

To add music:
1. Put an MP3 inside assets/
2. In script.js, replace the sound button section with your preferred Audio("assets/song.mp3") logic.
